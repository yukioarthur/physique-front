Fluxo de conexão

  1. GitHub Pages envia requisição pelo navegador.
  2. CORS valida a origem https://yukioarthur.github.io.
  3. API Key valida o header X-API-Key.
  4. Rate limit aplica limites por plano.
  5. Idempotência protege POSTs críticos com Idempotency-Key.
  6. Spring Boot consulta ou grava dados no MySQL.
  7. Render devolve JSON para o frontend.
