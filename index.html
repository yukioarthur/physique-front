Versionamento

X-API-Version

Permite testar V1/V2 mantendo o mesmo path, como GET /treinos/{id}.

Idempotência

Idempotency-Key

POSTs críticos podem ser repetidos sem duplicar dados quando a chave e o payload são iguais.

Como GitHub Pages, CORS, API e banco se conectam

inspeção

      
  1. O usuário abre o frontend publicado no GitHub Pages.
  2. O navegador envia uma requisição para a API com origem window.location.origin.
  3. Se houver headers customizados, o navegador envia antes uma requisição OPTIONS.
  4. A API responde o preflight com Access-Control-Allow-Origin, métodos e headers permitidos.
  5. A requisição real segue com X-API-Key, X-API-Version e, em POST crítico, Idempotency-Key.
  6. O backend valida API Key, rate limit, idempotência, Bean Validation e regra de negócio.
  7. Os dados são consultados ou gravados no MySQL da faculdade.
  8. O Beekeeper confirma se os dados foram gravados sem duplicidade.
